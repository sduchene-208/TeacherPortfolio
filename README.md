# Jennifer Morgan — Professional Portfolio

Static portfolio built with semantic HTML5, CSS3, and vanilla JavaScript.

## Files
- `index.html` — portfolio content and structure
- `styles.css` — responsive visual system
- `script.js` — mobile navigation
- `assets/` — reserved for approved public assets

## Editing
Look for `EDIT:` comments in `index.html` before publishing.

## Source / accuracy
Portfolio copy is based on the supplied Jennifer Morgan résumé. No unsupported student outcomes, metrics, or confidential information were added.

## Resume
A résumé PDF was not supplied in the source materials used for this build. Add an approved PDF under `assets/` and a verified download link before publication if desired.

## Deployment
For Build & Launch, deploy the static files to the client-owned GitHub repository and configure GitHub Pages.
